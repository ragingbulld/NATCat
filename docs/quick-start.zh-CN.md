# NATCat 简易使用教程

这个教程适合下面这种场景：

- 宽带运营商是电信、联通或移动等常见家庭/商宽线路。
- 你可以登录拨号设备后台，比如光猫、主路由或 RouterOS。
- 拨号设备支持设置端口转发、虚拟服务器或 dst-nat。
- 你有一台局域网设备可以运行 NATCat，比如 Linux 服务器、NAS、软路由或旁路机。
- 你要暴露的服务已经在局域网内运行，例如游戏服、Web 服务、SSH 或其他 TCP/UDP 服务。

NATCat 不负责转发业务流量。它只负责用指定的本地绑定端口建立保活连接，并探测这个端口对应的公网地址。真正的入站流量仍然需要由拨号设备的端口转发规则转发到目标设备。

## 1. 准备信息

先确认这几个值：

| 项目 | 示例 | 说明 |
| --- | --- | --- |
| 协议 | TCP | 服务使用 TCP 就选 TCP，使用 UDP 就选 UDP |
| NATCat 绑定端口 | 25565 | NATCat 用这个本地端口建立公网映射 |
| 目标设备 IP | 192.168.1.50 | 真正运行服务的局域网设备 |
| 目标服务端口 | 25565 | 真正服务监听的端口 |
| NATCat 设备 IP | 192.168.1.20 | 运行 NATCat 的局域网设备 |

绑定端口和目标服务端口可以相同，也可以不同。实际访问时使用 NATCat 显示出来的公网端口。

## 2. 启动 NATCat

在局域网设备上运行 NATCat：

```sh
./natcat --listen 0.0.0.0:8080
```

第一次启动会在终端打印初始账号密码：

```text
Initial login: admin / 随机密码
```

然后在浏览器访问：

```text
http://NATCat设备IP:8080
```

例如：

```text
http://192.168.1.20:8080
```

## 3. 创建实例

进入 WebUI 后创建一个实例：

1. 选择协议：`TCP` 或 `UDP`，必须和目标服务协议一致。
2. 绑定端口填写你希望占用的端口，例如 `25565`。
3. TCP 保活服务器选择 HTTP 组或自定义 HTTP 地址。
4. UDP 保活服务器选择 QUIC 组或自定义 QUIC 地址。
5. STUN 服务器可以使用默认组，也可以填写自定义 STUN 服务器。
6. 保存并启用实例。

实例启动后，NATCat 会显示公网地址，格式类似：

```text
公网IP:公网端口
```

例如：

```text
123.45.67.89:25565
```

这个地址就是外网用户应该访问的地址。

## 4. 设置拨号设备端口转发

登录光猫、主路由或拨号设备后台，找到下面任意一种功能：

- 端口转发
- 虚拟服务器
- NAT 转发
- dst-nat
- Port Forwarding

新增一条规则：

| 项目 | 应填写内容 |
| --- | --- |
| 协议 | 与 NATCat 实例相同，比如 TCP 或 UDP |
| 外部端口 | NATCat 的绑定端口 |
| 内部 IP | 目标设备 IP |
| 内部端口 | 目标服务端口 |

示例：把 TCP `25565` 转发到 Minecraft 服务器：

| 项目 | 示例 |
| --- | --- |
| 协议 | TCP |
| 外部端口 | 25565 |
| 内部 IP | 192.168.1.50 |
| 内部端口 | 25565 |

注意：这里转发到的是目标服务设备，不一定是运行 NATCat 的设备。

## 5. 外网访问

让外网设备访问 NATCat 显示的公网地址：

```text
公网IP:公网端口
```

如果是 Minecraft、游戏服或其他客户端，就在客户端里填这个地址。如果是 Web 服务，就访问对应协议和端口。

不要在同一个局域网内直接用公网地址测试，有些路由器不支持 NAT 回环。最好用手机流量、外地服务器或朋友的网络测试。

## 6. 常见问题

### NATCat 显示了公网地址，但外网连不上

优先检查：

- 路由器端口转发协议是否和实例协议一致。
- 外部端口是否等于 NATCat 的绑定端口。
- 内部 IP 是否填了真正运行服务的设备 IP。
- 目标服务是否已经监听在目标端口。
- 目标设备防火墙是否放行这个端口。
- 不要用内网设备访问公网地址作为唯一测试结果。

### 公网端口不是我填写的绑定端口

这通常说明拨号设备没有给这个本地端口映射相同公网端口，或者端口已经被其他连接占用。可以尝试：

- 换一个绑定端口。
- 停止占用该端口的其他实例或程序。
- 使用端口范围，例如 `20000-20010`。
- 绑定端口填写 `0` 让 NATCat 自动选择可用端口。

### 运营商是公网 IP 还是 CGNAT 怎么判断

如果拨号设备后台显示的 WAN IPv4 和外部网站看到的公网 IPv4 完全不同，可能处于 CGNAT 后面。CGNAT 场景下，普通端口转发通常无法从公网直接访问。

### UDP 服务为什么不好测

有些 UDP 服务收到探测包不会回包，所以无法像 TCP 一样通用地检测连通性。UDP 是否可用，最好用对应业务客户端从外网实际连接测试。

## 7. 最小配置示例

假设：

- 目标服务：`192.168.1.50:25565`
- 协议：`TCP`
- NATCat 绑定端口：`25565`
- NATCat 设备：`192.168.1.20`

操作顺序：

1. 在 `192.168.1.20` 启动 NATCat。
2. WebUI 创建 TCP 实例，绑定端口填 `25565`。
3. 路由器新增 TCP 端口转发：外部 `25565` -> `192.168.1.50:25565`。
4. 等 NATCat 显示公网地址。
5. 外网访问 NATCat 显示的 `公网IP:公网端口`。
